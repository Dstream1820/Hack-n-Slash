# Hack-n-Slash

Proyek game action 2D side-scrolling bergaya pixel art retro untuk Android.

## Status
Prototipe awal. Karakter yang sedang dirancang: Assassin. Basic Attack: combo 3 hit cepat tanpa efek khusus.

## Rencana awal
- Pemilihan karakter (sementara Knight dan Assassin direncanakan)
- Gerakan side-scrolling
- Basic attack 3 hit
- Animasi idle, berjalan, menyerang, dan menerima damage

Aset dan implementasi gameplay akan ditambahkan bertahap.
